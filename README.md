# Automotive Marketing ROI Calculator

This project provides a simple web tool for car dealers to calculate their digital marketing return on investment (ROI). It is built with React, TypeScript and Tailwind CSS using Vite.

## Features

- **ROI Calculator** – estimate monthly revenue, profit and ROI based on your marketing spend and lead data.
- **Trend Chart** – visualize how your ROI changes over time as you update the calculator.
- **Digital Marketing Basics** – a short guide explaining common terms and channels so dealers can better understand online marketing.
- **FAQ and Tips** – quick answers to common questions and advice for improving results.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the provided local URL in your browser.

Use the calculator to experiment with different budgets, lead values and conversion rates. Review the Digital Marketing Basics section for an overview of key concepts.
